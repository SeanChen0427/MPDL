# 下載元件

執行 `../安裝元件.command` 安裝官方 yt-dlp，檔案會放在此資料夾。

- 版本：`2026.08.19`
- 官方檔案：https://github.com/yt-dlp/yt-dlp/releases/download/2026.08.19/yt-dlp
- SHA-256：`1fa6733c37ea6fb51c99ad8fe785e7b7e5f3246c9b980230329d4fb72ed8d4d6`
- 官方專案與授權：https://github.com/yt-dlp/yt-dlp

儲存庫不包含下載元件執行檔；安裝程式下載後會核對 SHA-256。TubeDrop 使用 Python 執行這份官方 zipimport 檔案，需 Python 3.10 以上。
