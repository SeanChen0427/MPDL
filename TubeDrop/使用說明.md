# TubeDrop 測試版

雲端版：開啟已部署的 HTTPS 網址即可使用，不需啟動 Mac。下載記錄依瀏覽器隔離，檔案完成後暫存約一小時；請及時儲存。正式網址須以部署結果為準。以下為 Mac 本機版使用方式。

雙擊「啟動.command」即可開啟網頁。貼上 YouTube、Instagram（IG）或 Facebook（FB）的公開影片網址，選 MP4 或 MP3，按「開始下載」。完成後按「儲存檔案」。若更新前已啟動工具，先在原啟動視窗按 Control+C，再重新雙擊啟動。

可貼上的連結：

- YouTube：單支影片、Shorts、live、embed 或 youtu.be 分享連結。
- IG：Reels（`/reel/`、`/reels/`）、含影片的貼文（`/p/`）、IGTV（`/tv/`），也接受帶帳號名稱的 Reel 網址。分享連結中的追蹤參數會移除。若拿到 `/share/` 網址，請先在瀏覽器開啟，再複製影片的完整 `/reel/` 或 `/p/` 網址。
- FB：Reels、Watch、`/videos/`、含影片的貼文、story.php 與 permalink.php 影片貼文。接受常見手機版、網頁版、地區版網址。`fb.watch`、`/share/r/`、`/share/v/`、`/share/p/` 會嘗試跟隨 Facebook 的重新導向取得影片；若平台要求登入、沒有提供重新導向或無法解析，請改貼 `/reel/`、`/videos/` 或 `/watch/?v=` 的完整影片網址。

不支援個人首頁、粉專首頁、整個帳號、相簿、限時動態或純圖片下載。多影片貼文只下載第一支影片，不會批次抓取整篇貼文；`img_index` 不會改變選取的影片。IG／FB 即使是公開內容，也可能因平台要求登入或流量限制而失敗。

手機：與 Mac 連接同一 Wi-Fi，按「複製手機連線網址」，傳到手機瀏覽器開啟。Mac 必須保持開機，啟動視窗不可關閉。若 macOS 詢問是否允許 Python 的區域網路連線，需允許才能供手機使用。部分訪客 Wi-Fi 不允許裝置互相連線。

這是區域網路測試版，尚未發布為可從外網使用的網站。網址內含本次啟動的存取碼，請只提供給要使用的人。每次重新啟動會更換存取碼。

MP4 可選最高可用、4K、2K、1080p 或 720p 上限；實際畫質取決於來源。來源若沒有回報尺寸或沒有符合上限的格式，請改選「最高可用畫質」。高畫質 MP4 可能使用 AV1／VP9 等編碼，舊裝置的播放器不一定支援。MP3 以 320 kbps 輸出，轉檔不會增加來源原本沒有的音質。沒有音軌的影片只能存 MP4，選 MP3 時會提示改選格式。

檔案保留在 downloads 的各下載資料夾；取消後可能留下未完成的暫存檔，可在停止工具後自行刪除。網頁下載記錄不會在工具重新啟動後保留，已完成檔案仍留在資料夾。關閉啟動視窗或按 Control+C 即可停止。

目前一次處理一支影片，最多排入三筆工作。不批次下載播放清單，也不會讀取瀏覽器登入資料。需登入、會員、私人、地區限制或反機器人驗證的影片可能失敗。下載記錄會顯示來源平台；失敗時先顯示中文提示，可展開「查看技術訊息」查看原始原因。

此版本已針對本機環境設定：FFmpeg、Node.js 與 Codex 附帶 Python 3.12；移至其他電腦時需安裝對應元件。官方 yt-dlp 位於 bin/yt-dlp，可替換為官方新版。來源：https://github.com/yt-dlp/yt-dlp 。

請下載自己擁有或已獲授權的內容。
