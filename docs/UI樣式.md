# 熊恩Sean 系列介面

本工具沿用既有「產品照片一鍵下載工具（imgD）」、「IG 受眾分析工具」及「AI 逐字稿轉教材」的系列視覺。

- 品牌：熊恩Sean 社群經營 x AI實戰 課程專屬。
- 圓形頭像：使用既有課程素材，放在 `TubeDrop/web/assets/course-logo.jpg`，由本機提供。
- 背景：slate-50 `#f8fafc`；正文 slate-800 `#1e293b`。
- 主色：indigo-600 `#4f46e5`，互動深色 indigo-700 `#4338ca`。
- 白色卡片：24px 圓角、細邊框、小陰影；主要按鈕 12px 圓角。
- 步驟標籤：靛紫膠囊，分為連結、儲存、手機操作三段。
- 內容寬度：最大 896px；手機改為單欄，社群連結兩欄。
- 頁尾：Connect with Sean、Instagram／Facebook／Threads／LINE，以及系列署名。
- 使用系統字體、原生 HTML／CSS／JavaScript、內嵌 SVG 圖示；不載入 CDN 或遠端頭像。
